PDF 自动高亮测试说明

1. 检查控制台日志

打开浏览器开发者工具（F12），查看 Console 标签页，应该看到：

PDF document loaded
PDF auto-search triggered for: [搜索关键词]
Found X matches for "[搜索关键词]"

2. 验证数据流

确认以下数据正确传递：

  • source.quote 字段存在且不为空
  • searchKeyword 正确传递到 PdfLightbox 组件
  • documentLoaded 状态变为 true

3. 检查 CSS 动画

高亮元素应该有 .rpv-search__highlight 类名，并应用动画：

animation: pdf-highlight-pulse 2.5s ease-out forwards;

4. 可能的问题

  • 问题1: source.quote 为空 → 检查后端返回的数据
  • 问题2: PDF 文本层不完整 → OCR 质量问题
  • 问题3: 搜索关键词不匹配 → 尝试简化关键词

5. 调试步骤

  1. 在问答界面提问，获取带参考资料的回答
  2. 打开开发者工具 Console
  3. 点击"查看 PDF"按钮
  4. 观察控制台输出和 PDF 高亮效果
